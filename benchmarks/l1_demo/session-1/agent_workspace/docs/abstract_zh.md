> 译自 Aurora 合作项目投稿摘要

大语言模型能够从已发布文本中分散的语义与上下文线索推理出敏感属性，即使显式标识符已被移除也是如此。现有匿名化方法往往对隐私相关证据采取统一处理，这可能留下残余的推理路径，或者不必要地压缩为保留用户交流意图所需的内容。我们提出 \textsc{IntentAnony}，一个意图约束的暴露控制框架，它将语用意图与属性特定的隐私证据相联系，并在显式策略约束下调控已发布文本中保留的推理支持度。候选改写在发布前还会进一步针对残余推理风险与意图一致性进行验证。关键在于，意图相关性仅被视为一种效用约束：它既不授权披露，也不改变属性成功恢复情形下的隐私状态。在 Personal Reddit 与 SynthPAI 数据集上，\textsc{IntentAnony} 在精选的非意图目标上取得了优于遮盖、改写以及基于大语言模型的匿名化基线的隐私–效用权衡，同时语义与意图保留评估表明其具备更强的交流效用。然而，跨模型评估揭示了显著的、依赖攻击者与数据集的差异，凸显了持续存在的残余推理风险。这些结果展示了意图约束暴露控制在已评估场景下的实证价值，但并不暗示对意图相关属性或任何形式隐私保证的保护。
