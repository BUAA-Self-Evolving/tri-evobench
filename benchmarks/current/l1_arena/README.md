# L1-Arena: self-contained persistent workspace streams

L1-Arena converts the real-source-grounded `clawarena-real` release into the same stream-oriented packaging style as `l1_life_v2`. Every ClawArena scenario is one isolated persistent stream, and every original evaluation round is one ordered `turnK/task.json`.

The release contains **23 streams and 423 turns**: 377 one-to-one source `exec_check` turns plus 46 deterministic derived distractors. Each stream receives one unrelated exact-answer interruption after source round 5 and one explicit one-turn formatting override after source round 10. The distractors test context switching and persistent-state hygiene without requiring another scenario workspace. All source turns preserve the original verifier, feedback, preference check, description, update IDs, and ordering.

## Runtime boundary

The Agent process receives a mount containing only `agent_workspace/workspace`; setting cwd without a mount/chroot boundary is forbidden. Session histories are exposed only through `SessionHistory`. `evaluation/`, `facts.json`, manifests, checker feedback, structured GT, and update payloads remain unmounted. Before an update-bearing turn, the evaluator/runtime applies the sealed `evaluation.environment_updates` actions and registers new sessions in `sessions.json`.

Every one of the 423 turns embeds a non-null bounded L1 User Simulator based on the L2 post-failure Interaction contract. A valid Agent failure with remaining budget may produce one concise retry user message per invocation, at most two messages after the initial Interaction. Arena enables no hidden-fact clarification. The simulator sees only public task/transcript/latest response plus bounded feedback and cannot access checkers, GT, exact expected values, future turns, or sealed state.

Bounded feedback is generated by the packaged `l1_bounded_feedback/1.0` dimension-and-score-only projector; preference adherence is a mandatory success component; Judge/control-plane failures remain null. Retry Interactions use `continue_with_patch` and do not reapply environment updates.

Official task success remains source-faithful: run `evaluation.primary_evaluation.source_exec_check` and use binary pass/fail. The task-only and preference-only verifiers provide non-overlapping L1 ordinal checks; a missing preference target is failure, not a successful skip. The public task/evaluation fields follow the L1 v2 loader contract while Arena-specific deterministic fields remain explicit extensions.

Distractors use `turn_type=distractor`, `turn_origin=derived_evolution_turn`, `sequence_role=noise`, no tools, an exact short-answer check, and a state-hygiene check forbidding workspace/session/learner mutation. They consume no ClawArena source round and never change cumulative update visibility.

Every turn also carries a bilingual top-level `tag` with `domain`, `domain_zh`, `subtag`, `subtag_zh`, and `is_noise`. Source subtags combine a scenario topic with a frozen, reviewed per-round intent from `taxonomy/tag_intent_gold.json`; distractors use the dedicated `unrelated_noise / 无关噪音` domain rather than inheriting the stream's business domain. Root and stream manifests publish deterministic tag counts and the gold SHA-256.

Build or validate with `python scripts/build_l1_arena.py` and `python scripts/build_l1_arena.py --check`.
