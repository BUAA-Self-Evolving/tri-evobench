# Materialized Telecom policy excerpt

Adapted from `data/tau2/domains/telecom/tech_support_workflow.md`, Path 2.1 (Unavailable Mobile Data Troubleshooting), at revision `a2c024725189473d2d7cea3a5cfdbcc67478e41f`.

1. Ask the user to run a speed test. A “no connection” result means mobile data is unavailable.
2. Verify service is available, then ask the user to rerun the speed test.
3. If the user is traveling, check whether Data Roaming is enabled on the phone.
4. If Data Roaming is off, ask the user to turn it on and rerun the speed test.
5. If Data Roaming is already on but mobile data still fails, verify that the carrier line permits roaming; enable it at no cost if necessary, then retest.
6. Continue to mobile-data settings and usage troubleshooting only if connectivity still fails.
